# Roadmap

## After v0.14 in-game verification

- Window-watching behavior using validated outside positions.
- Non-destructive sign messages.
- Sleep encounters.
- A safe basement blueprint generated only on flat, clear terrain.
- Optional haunting progression reintroduced as a configurable mode.
- Additional house variants loaded from tested blueprints.
- Automated content-log regression checklist for each Bedrock update.

Features return one at a time only after the current build/pathfinding layer passes testing.
