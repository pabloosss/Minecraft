# 01 — Logo MineBox — prompt do kopiowania

## Zapisz wygenerowany plik jako

```text
static/img/logo-minebox.png
```

## Prompt — kopiuj całość jednym kliknięciem

```text
Create a 512x512 transparent PNG logo for a project called MineBox. The logo should be an original pixel-art / voxel-style icon inspired by block-building games, but it must not use the official Minecraft logo, Mojang assets, Minecraft characters, creepers, Steve, or any copyrighted game artwork. Show a dark stone cube combined with a small compact server box, with glowing emerald green accents, subtle network glow, clean modern game-hosting style, high contrast, centered composition, sharp readable silhouette, premium product icon look, transparent background, no text, no watermark.
```
